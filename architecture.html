Ripple — Multi-Agent Architecture

Google Cloud ADK · Gemini · A2A Protocol · Dynatrace MCP · GitLab REST API · MongoDB Atlas

A2A Pipeline Flow

  • • GitLab webhook fires on PR open/update
  • • Orchestrator calls Intelligence via A2A
  • • Intelligence extracts semantic risk pattern
  • • Scanner fans out — one agent per service
  • • Fix Factory generates + evaluates fixes in parallel
  • • Fix MRs opened in GitLab with incident context embedded

Three MCPs

  • • Dynatrace — primary track: incident history, traces, service maps
  • • GitLab — secondary: codebase read/write, MR creation, fix precedent
  • • MongoDB — tertiary: scars & wins, vector search, risk adjustment
  • • Pattern grounded in real production failure data
  • • "47-min outage, £23k" quantification on every PR

Institutional Memory

  • • MongoDB stores every scan outcome as Scar or Win
  • • Scars: rejected fixes, intentional patterns, risk –2
  • • Wins: merged fixes, zero incidents since, confidence +1
  • • Vector search finds similar past cases on new PRs
  • • Scanner agents briefed with per-service history
  • • System improves with every merged or rejected MR
