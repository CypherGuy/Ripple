Ripple - Multi-Agent Architecture

Google Cloud Rapid Agent Hackathon · Dynatrace Track · Google ADK + Gemini 3 Flash · June 2026

Data Sources

  • • Dynatrace: incident history, service maps, failure traces via MCP
  • • GitLab REST API: source files, MR history, fix precedents
  • • MongoDB Atlas: institutional scars, wins, vector-search patterns
  • • Gemini 3 Flash: model for all four ADK LlmAgents via AI Studio

Agent Pipeline

  • • Google ADK LlmAgent + FunctionTool across all four services
  • • A2A agent-to-agent HTTP calls wire the pipeline end-to-end
  • • asyncio fan-out: one scanner agent per service, all in parallel
  • • Self-correction loop: eval agent re-fetches real Dynatrace traces

Institutional Memory

  • • Scars: rejected fixes lower future risk scores for that pattern
  • • Wins: merged fixes with no incidents raise confidence scores
  • • Atlas Vector Search (text-embedding-004, 768-dim cosine)
  • • OTel spans shipped to Dynatrace; Ripple observes itself
