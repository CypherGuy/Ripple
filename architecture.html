Ripple - Multi-Agent Architecture

Google Cloud Rapid Agent Hackathon · Dynatrace Track · Google ADK + Gemini · June 2026

Data Sources

  • • Dynatrace: incident history, service maps, failure traces
  • • GitLab: codebase, fix history, MR metadata
  • • MongoDB: institutional scars, wins, pattern scores
  • • Vertex AI: Gemini model shared across all four services

Agent Pipeline

  • • Google ADK orchestration across four microservices
  • • A2A protocol wires every service-to-service call
  • • asyncio fan-out: one agent per target service
  • • Self-correction loop before any MR is opened

Institutional Memory

  • • Scars: rejected fixes with learned context & risk penalty
  • • Wins: merged fixes with no incidents since merge
  • • Vector search surfaces similar past cases at scan time
  • • Scanner agents briefed with per-service history
